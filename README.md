# App Drawer

Aplicativo Android desenvolvido em Kotlin para praticar a implementação de um menu lateral de navegação, conhecido como Navigation Drawer.

## Funcionalidades

- Abertura do menu lateral pela barra superior.
- Menu com as opções Início, Configuração e Perfil.
- Atualização do conteúdo principal conforme a opção selecionada.
- Fechamento automático do menu após a seleção.

## Tecnologias utilizadas

- Kotlin
- Android SDK
- AndroidX
- DrawerLayout
- Material Components
- NavigationView
- XML

## Como executar

1. Clone o repositório.
2. Abra o projeto no Android Studio.
3. Aguarde a sincronização do Gradle.
4. Execute o aplicativo em um emulador ou dispositivo Android.

## Objetivo do projeto

Praticar a construção de interfaces Android, implementação de menus laterais, navegação entre opções e interação com componentes visuais.
